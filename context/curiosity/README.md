# Curiosity Files

Nothing in this folder is required or graded on HW3. Each file exists because real projects,
real agent frameworks, or real teams have found a use for it, and because the eleven-file
scaffold is a floor rather than a ceiling.

Fill one in if a question grabs you. Engagement credit is available for a thoughtful attempt.
Leave the rest alone; an empty curiosity file is honest, and a fake one is not.
